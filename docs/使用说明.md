# osu2tja 上手说明

把 **osu! 的 taiko 谱面（`.osu`）** 转成**太鼓之达人模拟器能直接读的 `.tja`**，
连音频一起打包好，丢进模拟器就能打。

这个说明是写给第一次用的人的。不用懂 TJA 格式，也不用懂代码。

## 1. 先确认你要的东西在这里

文件夹里能双击运行的有两个：

| 文件 | 作用 |
| --- | --- |
| `osu2tja2.bat` | **高难版**，双击打开图形界面 |
| `osu2tja2-low.bat` | **低难版**，双击打开图形界面 |

另外几个文件是给命令行和开发者用的，先不用管：

| 文件 | 作用 |
| --- | --- |
| `osu2tja2.py` | 真正的转换引擎（两个 bat 都调它） |
| `osu2tja_low.py` | 低难版入口，只是把难度表换一下 |
| `README.md` | 技术向说明（原理、参数全表） |
| `docs/` | 文档目录，你正在看的这份就在里面 |

## 2. 准备环境（只需一次）

### 2.1 Python

需要 **Python 3.8 或更新的版本**。

1. 到 <https://www.python.org/downloads/> 下载安装包。
2. 安装时**务必勾选** `Add python.exe to PATH`（在安装界面最下面）。
3. 装完打开「命令提示符」，输入：

   ```
   py --version
   ```

   能打印出版本号（例如 `Python 3.13.2`）就对了。

> **为什么要用 `py` 而不是 `python`？**
> Windows 上可能装了好几个 Python。`py` 是官方启动器，会挑一个能用的。
> 有些精简版 / 商店版 Python 不带图形界面库（tkinter），双击 bat 会闪退 —— 用官网
> 安装包装就不会有这个问题。

### 2.2 ffmpeg（要转音频才需要）

转换器会把音源统一转成 **OGG**。如果源音频本来就是一个 `.ogg` 文件，那不需要
ffmpeg（直接拷贝）；如果源是 `.mp3`，就需要 ffmpeg 来转码。

两种放法，任选其一：

- 装到系统 PATH 里（`winget install ffmpeg`，或官网下载后加进 PATH）；
- 或者直接把 ffmpeg 解压到 `C:\ffmpeg\`，让它出现在 `C:\ffmpeg\bin\ffmpeg.exe`。

转换器会自己去这两个地方找。找不到也不会静默失败 —— 它会明确告诉你
「没找到 ffmpeg」，此时 `.tja` 照样转出来，只是不带音频。

## 3. 三步转出第一个谱面

### 第 1 步：找到你的 osu! 谱面文件夹

osu! 把所有谱面放在 `Songs` 里，一个谱面包一个文件夹：

```
C:\Users\<你>\AppData\Local\osu!\Songs\<作者> - <曲名>\     ← 常见位置
D:\osu!\Songs\<作者> - <曲名>\                              ← 装在别的盘时
```

**你不用自己去翻**：转换器第 1 步就是个谱面浏览器，会自动扫 `Songs`。

### 第 2 步：双击 `osu2tja2.bat`

弹出的是一个**谱面列表**，不是 Windows 文件框。顶上有一条搜索框，输入曲名
或曲师的关键词就能过滤。列表里能看到曲名、曲师、难度名、★ 星数、音符数、文件夹。

想选哪几个，就点哪几行（按住 `Ctrl` 或 `Shift` 可以多选）。选好按「确定」。

> 想转 `Songs` 以外的谱面？点窗口里的「用文件管理器…」，会退回系统的选择框。

### 第 3 步：选输出文件夹

选一个空文件夹（或者新建一个）。转换器会在里面**按曲名建子文件夹**：

```
<你选的文件夹>\<曲名>\<曲名>.tja
<你选的文件夹>\<曲名>\<音源名>.ogg
```

转完会弹一条结果提示，然后就结束了 —— 不会自动打开文件夹。

## 4. 两个版本：高难版 / 低难版

区别只在**「给了 N 张谱面时，它们分别叫什么难度」**。转换质量完全一样（同一份引擎）。

| 同一首歌给几张 | 高难版 `osu2tja2.bat` | 低难版 `osu2tja2-low.bat` |
| --- | --- | --- |
| 1 张 | 鬼 | 鬼 |
| 2 张 | 里、鬼 | 鬼、困难 |
| 3 张 | 里、鬼、困难 | 鬼、困难、普通 |
| 4 张 | 报错 | 鬼、困难、普通、简单 |
| 5 张 | 报错 | 里、鬼、困难、普通、简单 |

**怎么选：**

- 你要转的是 **鬼级 / 里谱级别的高难谱** → 用高难版。
  它故意只到「困难」为止，因为模拟器的「简单 / 普通」判定比 osu 宽松得多，
  把高难谱硬标成「普通」会变成名不副实的假难度。
- 你要转的是**一整套从简单到鬼的谱面**（osu 里本来就分好了难度）→ 用低难版。

**两个版本都遵守同一条规则：星数高的那张，拿更高的难度名。**

所以你给谱面的**顺序无所谓** —— 谁难谁软，转换器按 ★ 星数自己排。
只有两张谱的 ★ 完全一样（屏幕上分不出谁更难）时，它才会弹窗问你想让谁排前面。

> ★ 星数的来源是 osu! 自己的 `osu!.db` 缓存，不是猜的。读不到时才用备用库估算。

## 5. 界面详解

### 第 1 步：谱面列表

- **只显示 taiko 谱面**。osu!standard / catch / mania 的谱面不会出现在列表里（转换器只认
  `Mode: 1`）。所以「我明明有这张谱却搜不到」通常是因为它是 std 谱，不是 taiko 谱。
- **搜索框**：整串优先匹配；没有整串结果时再按空格拆词，要求每个词都命中。
  例如搜 `Talk uone` 会同时匹配「曲名含 Talk」和「曲师含 uone」。
- **表头**：点一下按那一列排序，再点一下反向。数字列（★、音符、大小、时间）第一次点
  是降序，方便直接看最大的。
- **右键菜单**：「选中这首歌的全部谱面」—— 一键把同一个文件夹里的所有难度都选上，
  这是转多难度最常用的操作。
- **双击 / 回车**：确认选择。
- **多选**：`Ctrl` 点选单个，`Shift` 选一段。
- **底栏**：一直显示「共多少张 / 涉及多少首歌 / 已选多少」，免得漏选或多选。

第一次扫描要几秒（几千个谱面文件），之后有缓存，再打开是瞬开。

> 缓存位置：`%APPDATA%\osu2tja2\maps_cache.json`。
> 谱面文件改动过（改了难度、重新下载）会自动重新扫那一条。

### 第 2 步：排难度顺序（只在星数打平时出现）

绝大多数情况不会出现这一步。只有在**同一首歌里有两张谱的 ★ 完全相同**、
程序分不出谁更难时，才会弹一个排序窗口，让你决定谁排前面。

窗口里按「同一首歌 · ★N」分组，跨组不能上下移动。

### 最后一步：选输出位置

选好文件夹就行。程序会记住这个位置，下次打开直接沿用 ——
想恢复成每次都问，用 `--forget-out-dir` 参数启动一次（见第 9 节）。

## 6. 输出长什么样

### 文件结构

```
你选的文件夹\
    Checklist (feat. Chromeo)\
        Checklist (feat. Chromeo).tja
        audio.ogg
    One of Us\
        One of Us.tja
        One of Us.ogg
```

一个曲名一个文件夹。**音源和 `.tja` 必须放在一起**，模拟器按 `.tja` 里的 `WAVE`
字段找同目录的音频。

不想让程序建子文件夹（全部平铺到选定目录），加 `--flat`。但**批量转多首歌时
`--flat` 不生效** —— 很多歌的音源都叫 `audio.ogg`，平铺会互相覆盖。

### `.tja` 文件里写了什么

真转一份出来是这样（`debug/Checklist (feat. Chromeo)` 的实际输出）：

```tja
TITLE:Checklist (feat. Chromeo)
ARTIST:MAX
SUBTITLE:--MAX
BPM:123
WAVE:audio.ogg
OFFSET:-0.270
DEMOSTART:19.508
SONGVOL:100
SEVOL:100
SCOREMODE:2
//Converted from "MAX - Checklist (feat. Chromeo) (_gt) [123  abc].osu" by osu2tja2

COURSE:Oni
LEVEL:14
#START
...
```

| 字段 | 说明 |
| --- | --- |
| `TITLE` / `ARTIST` | 曲名 / 曲师，默认取 osu 的「原名」字段 |
| `SUBTITLE` | 写成 `--曲师`，模拟器里会显示成副标题 |
| `BPM` | 起始 BPM（中途变化会写 `#BPMCHANGE`） |
| `WAVE` | 音源文件名 |
| `OFFSET` | 谱面起点相对音频的偏移（秒，负数表示音频先响） |
| `DEMOSTART` | 选曲预览从第几秒开始 |
| `SONGVOL` / `SEVOL` | 音乐 / 音效音量（固定 100） |
| `SCOREMODE` | 计分模式（固定 2 = 真打） |
| `COURSE` / `LEVEL` | 难度名 / ★ 星数 |
| `BALLOON` | 气球（连打）要求的击打数，多个用逗号分隔 |

最后那行 `//Converted from ...` 是注释，记录源文件名 —— 不出现在任何界面里，
纯粹方便你日后核对这份 `.tja` 是从哪张谱转来的。

多难度时，`TITLE/BPM/WAVE/OFFSET/DEMOSTART` **只写一次**（文件头），
下面每段各写一份 `COURSE` + `LEVEL`，用 `#START` / `#END` 包起来。这就是本家谱面的形态。

### 难度名用的是哪几个词

模拟器只认这五个：`Easy` / `Normal` / `Hard` / `Oni` / `Edit`。

- `Oni` = 鬼（魔王）
- `Edit` = 里谱（Inner / Ura）
- 中文界面里看到的「鬼 / 困难 / 普通 / 简单」就是 `Oni / Hard / Normal / Easy`

> 注意：里谱写的是 `Edit`，不是 `Ura`。有些模拟器认 `Ura`，但 OpenTaiko / TJAPlayer3
> 不认，所以统一用 `Edit`。

## 7. 常用选项

图形界面已经覆盖了最常用的场景。下面这些需要走命令行：

| 选项 | 干什么 | 什么时候用 |
| --- | --- | --- |
| `-o 目录` | 指定输出目录 | 不想用上次记住的位置 |
| `--flat` | 不建曲名子文件夹 | 只转一首、想直接放桌面 |
| `--course 困难` | 强制指定难度名 | 单张谱想标成「困难」而不是「鬼」 |
| `--level 12` | 强制指定 ★ 星数 | 觉得自动算的不对 |
| `--courses 里,鬼` | 多张时按顺序指定各段难度名 | 想手动控制（会给按你给的顺序，不再自动按星数排） |
| `--levels 15,14` | 多张时按顺序指定各段星数 | 同上 |
| `--title "曲名"` / `--artist "曲师"` | 强制指定曲名 / 曲师 | 源文件里写的是乱码 |
| `--keep-original-names` | 关掉乱码兜底 | 你确定原名没坏，不想被改成罗马音 |
| `--no-trim-audio` | 不裁音频尾巴 | 想保留完整的一整首歌 |
| `--trim-tail 5` | 尾巴留 5 秒余韵（默认 3 秒） | 歌结尾有长尾音被切掉了 |
| `--no-copy-audio` | 不输出音频 | 只想看 `.tja`，音频自己准备 |
| `--encoding utf-8` | 输出 UTF-8 编码（默认 cp932） | 模拟器显示乱码时试这个 |
| `--barline show` / `hide` | 强制显示 / 隐藏小节线 | 觉得小节线不该断在某个位置 |
| `--subdiv 8` | 基准每拍格数（默认 4） | 想让谱面文件更细 / 更粗 |
| `--forget-out-dir` | 忘掉记住的输出目录 | 换电脑、换项目时重置 |
| `--quiet` | 不打印摘要 | 批量跑脚本时 |
| `--gui` | 即使给了文件也弹窗 | 想在界面上确认一遍 |

完整参数表（含音频处理细节、OFFSET 换算）见 `README.md` 和 `python osu2tja2.py --help`。

## 8. 常见问题

### 双击 bat 一闪而过

说明 Python 没装好，或者 `py` 命令不可用。

先开命令提示符手敲一次，这样能看到报错信息：

```
py osu2tja2.py
```

- `'py' 不是内部或外部命令` → Python 没装，或没勾 PATH（重装时勾上）。
- `ModuleNotFoundError: No module named 'tkinter'` → 你用的是精简版 Python。
  换官网安装包，安装时保持默认组件（tkinter 是默认自带的）。

### 列表是空的 / 找不到我的谱面

程序默认扫 `%LOCALAPPDATA%\osu!\Songs`。如果你的 osu! 装在别的盘：

1. 在列表窗口里点「用文件管理器…」，手动选 `.osu` 文件；
2. 或者直接命令行指定路径（见第 9 节）。

### 转出来没有声音

按顺序查：

1. **音频文件在不在**？输出目录里应该有一个 `.ogg`，和 `.tja` 同目录。
2. **`WAVE` 字段对不对**？打开 `.tja` 看 `WAVE:` 后面写的文件名，必须和实际文件名
   一个字都不差（包括扩展名）。
3. **是不是用了 `--no-copy-audio`**？那个参数本来就不输出音频。
4. **模拟器不认这个格式**？转换器输出的都是 OGG/Vorbis，OpenTaiko 和 TJAPlayer3 都认。
   如果模拟器是别的（比如某些手机端），可能要 MP3。

### 提示找不到 ffmpeg

`.tja` 会正常转出来，只是不带音频。想要音频就装 ffmpeg（见 2.2），
或者干脆手动把原音频改成 `.ogg` 放进输出文件夹，并把 `.tja` 里的 `WAVE` 改成那个文件名。

### 曲名变成了拼音 / 罗马音

说明转换器判定源文件里写的原名是**乱码**，于是退回了罗马音那一栏，并会打印原因
（例如「TitleUnicode 疑似乱码」）。

这是**故意的兜底**：宁可给你一个能看懂的罗马音，也不要一个满屏问号的标题。

- 想保留原名：加 `--keep-original-names`。
- 想自己指定：加 `--title "正确的曲名"`。

> 源文件里的乱码是**还原不了**的 —— 那是一堆已经丢失的信息，不是编码问题。
> 想彻底修好，只能去 osu 里重新下载这张谱面。

### ★ 星数不对

星数优先从 osu! 的 `osu!.db` 缓存里读（这是 osu 官网显示的那个值）。
读不到时（比如谱面不是在 osu 里下的、或者你刚换了 osu 安装位置）才用备用库估算，
估算值可能偏高。

想手动改：`--level 14`。

### 一首歌有 6、7 个难度，装不下

模拟器只认 5 个难度。高难版最多 3 张、低难版最多 5 张。

超了会**直接报错并列出是哪几首歌**，一个文件都不写（不会偷偷截断你的谱面）。
解决办法：分两次转，或者先把不想要的难度删掉。

### 一次转很多首歌

可以。程序会按**文件夹**分组：同一个文件夹 = 同一首歌。
每首歌各自建一个文件夹，各转一个 `.tja`。

只要**某一首歌自己**不超过张数上限就行，总共有多少首歌无所谓。

批量时**必须**用 `-o` 指定输出目录（见第 9 节）。

### 音符看起来没对齐 / 和原谱不一样

先看**音符时刻**对不对（偏差通常在 3ms 以内，人的耳朵分辨不出来）。

如果你觉得「格子看起来乱七八糟」—— 那多半是那一小节的节奏太复杂（同一小节里
同时有七连音、九连音这种），单个网格排不下。转换器会把这种小节**自动拆成几段**
（用 `#MEASURE n/d`），每段用自己的网格。这在视觉上已经是能做到的最整齐的形式。

> 这类改动**不动音符时刻**，只改「一行写几个格子」。所以打起来的手感和时间点不受影响。

### 拖进模拟器看不到谱面

1. `.tja` 和音频必须在**同一个文件夹**里。
2. 模拟器通常要求文件夹名和 `.tja` 文件名有关联，别随意改。
3. TJAPlayer3 需要 `.tja` 放在它的 `Songs` 目录下（或你配置的扫描目录）。
4. 编码问题：默认写 cp932（日文模拟器惯例）。如果你的模拟器显示乱码，
   用 `--encoding utf-8` 重转一次。

## 9. 命令行速查

图形界面够用的话，这一节可以跳过。

```bash
# 转一个谱面，输出到谱面同目录
py osu2tja2.py "D:\osu!\Songs\xxx\yyy.osu"

# 转一个谱面，输出到指定目录
py osu2tja2.py "D:\osu!\Songs\xxx\yyy.osu" -o "D:\TJA"

# 同一首歌的三个难度 -> 一个多难度 .tja（高难版）
py osu2tja2.py a.osu b.osu c.osu -o "D:\TJA"

# 同一首歌的五个难度 -> 五档全开（低难版）
py osu2tja_low.py a.osu b.osu c.osu d.osu e.osu -o "D:\TJA"

# 批量：多首歌一次转（按文件夹自动分组，每首歌一个文件夹）
# ⚠ Windows 的 cmd 不展开通配符，批量请用下面两种办法之一：
#    ① 最省事：图形界面里多选（支持跨歌一起选）
#    ② 把这几个 .osu 一起拖到 osu2tja2.bat 上
#    ③ PowerShell 里可以显式展开：
#       py osu2tja2.py -o "D:\TJA" (Get-ChildItem "D:\osu!\Songs\*\*.osu").FullName

# 看全部参数
py osu2tja2.py --help
```

> 低难版 (`osu2tja_low.py`) 的参数和高难版**完全一样**，只是难度表不同。
> 想把命令写在脚本里批量跑，两版都支持 `--quiet`。

## 10. 它做得有多准 / 有哪些做不到

### 准的部分

- **音符种类**：咚 / 咔 / 大咚 / 大咔，全部按 osu 的 hitsound 判定，四种一一对应。
- **音符位置**：时刻误差通常 **≤3ms**（远小于人耳能分辨的 10~20ms）。
- **BPM 变化**：osu 的红线转成 `#BPMCHANGE`，并把红线时刻还原到音乐网格上
  （所以不会出现 `#MEASURE 167999/168041` 这种鬼东西）。
- **流速（SV）**：osu 的绿线转成 `#SCROLL`，并按整谱的 `SliderMultiplier` 归一。
  目标是「每条音符在屏幕上滚动的速度」和 osu 一致。
- **连打和气球**：slider → 连打（`5`/`6`），spinner → 气球（`7`/`8`），
  气球数按 osu 的点击数换算。
- **Kiai**：转成 `#GOGOSTART` / `#GOGOEND`。
- **音频**：统一转 OGG/Vorbis，并自动裁掉谱面打完之后那一大段没用的尾巴
  （只裁尾，绝不动开头 —— 动开头就得重算 OFFSET，风险不值）。

### 做不到 / 不做的

- **不能把 osu 的难度「翻译」成模拟器难度**。一张 osu 的 ★5 谱，转成 TJA 之后
  还是那个 ★5 的手感，不会因为标了「普通」就变简单。星数只是标签。
  所以高难版才刻意不往下铺到「普通 / 简单」。
- **判定宽度不一样**。osu 的 taiko 判定和太鼓本家 / 模拟器的判定不是一套标准，
  这一点转换器改不了 —— 它是格式转换，不是难度重制。
- **音源不匹配就没办法**。如果 osu 谱面和本家谱面用的不是同一份音频，
  两者的 OFFSET 之间没有任何可比性。
- **乱码修不了**。源文件字段坏掉就是坏掉，只能退回罗马音或你手动指定。
- **不处理 osu!standard / catch / mania 谱面**（只认 `Mode: 1`）。

## 附：文件都在哪

| 位置 | 内容 |
| --- | --- |
| `%APPDATA%\osu2tja2\config.json` | 记住的输出文件夹、上次浏览的谱面目录 |
| `%APPDATA%\osu2tja2\maps_cache.json` | 谱面列表缓存（删了会自动重建，只是下次慢几秒） |
| `<输出目录>\<曲名>\` | 转换产物：`.tja` + 音源 |

想彻底重置：删掉 `%APPDATA%\osu2tja2\` 整个文件夹，或者用 `--forget-out-dir`。
